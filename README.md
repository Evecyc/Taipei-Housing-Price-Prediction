# Taipei Housing Price Prediction

A machine learning project for predicting Taipei housing transaction prices using real estate transaction data and metro-related features.

------------------------------------------------------------------------

## 1. Project Overview

This project compares three regression models for Taipei housing total transaction price prediction:

-   Ridge Regression
-   Decision Tree
-   XGBoost

The original version was completed as a team course project. This GitHub version focuses on revising the modeling workflow to reduce potential data leakage.

------------------------------------------------------------------------

## 2. Contribution and Scope

My main responsibility was the modeling part, including data cleaning, model training, model comparison, sanity check, and result interpretation.

The input dataset `final_data.csv` was prepared by the team, combining Taipei housing transaction data with metro-related features. In this revised version, I focused on improving my own modeling workflow. The data collection and metro feature processing parts were not substantially modified.

The original housing transaction data was obtained from the Taipei City Open Data platform, specifically the Taipei Real Estate Transaction Weekly Report dataset.

## 4. Methodology

The revised workflow separates basic data cleaning from model preprocessing.

Main steps:

1.  Basic data cleaning
2.  Train-test split
3.  Pipeline-based preprocessing
4.  Model training and comparison
5.  Sanity check
6.  Feature importance analysis

All preprocessing steps that require fitting, such as imputation, encoding, scaling, and hyperparameter tuning, are performed within the training workflow.

## 6. Results

The following table shows the model performance on the holdout test set.

| Model            |    MAE |    RMSE |    R² |
|------------------|-------:|--------:|------:|
| XGBoost          | 571.36 |  868.90 | 0.934 |
| Ridge Regression | 862.25 | 1343.00 | 0.841 |
| Decision Tree    | 969.80 | 2340.02 | 0.518 |

XGBoost achieved the best overall performance on the holdout test set and was selected for further sanity check and feature importance analysis.

------------------------------------------------------------------------

## 7. Sanity Check

Since XGBoost achieved a high R² score, additional checks were conducted to examine whether the result was reasonable and stable.

| Model / Check | Description | R² |
|----------------------|--------------------------------|------------------:|
| Full XGBoost | All features on holdout test set | 0.934 |
| Area-only XGBoost | Only area-related features | 0.830 |
| XGBoost without detailed area | Removed `mb_area`, `sb_area`, and `pu_area` | 0.892 |
| XGBoost 5-fold CV | Mean ± standard deviation | 0.837 ± 0.112 |

The area-only model showed that area-related variables explain a large portion of total transaction price. After removing detailed area features, XGBoost still performed well, suggesting that the full model does not rely only on detailed area breakdown variables.

The 5-fold cross-validation result provides an additional stability check. Although the single holdout test result is higher, the model remains reasonably predictive across different data splits.

------------------------------------------------------------------------

## 8. Feature Importance

Permutation importance was used to interpret the XGBoost model.

The most important feature was `farea`, followed by features such as `district`, `case_t`, and metro-related variables. This is reasonable because the target variable is total transaction price, and building area is directly related to transaction value.
